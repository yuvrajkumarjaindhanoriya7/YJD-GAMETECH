Animation

Bring your maps to life, one frame at a time

YJD GameTech animates like a flipbook. A map shows one image, waits a few milliseconds, then swaps in the next one. Played fast enough, still pictures become a moving car, falling rain or a flickering lamp.

Try it

These four frames come from the demo street. Change the speed and the time of day to see how the same code behaves.

How it works

Four lines do the work

  • images is the list of frames, in order.
  • currentFrame remembers which frame is showing.
  • animateImages() sets the <img>'s src to the current frame, then moves to the next.
  • setInterval(animateImages, frameSpeed) repeats it every frameSpeed milliseconds. When the list ends, it jumps back to frame 0 and loops.

Choosing a speed

frameSpeedFPSGood for
10001Blinking signs, slow clouds
5002Gentle background loops
2504Traffic, water, flags
120~8Walking characters, fire

Code

Animation code

Start with your original Animation.js. Use the reusable version when one map needs several animations.

1. Animation.js (your original)

Put it at the end of a chunk that has <img id="main-image">. It loops forever.

Animation.js
// Images used in animation
const images = [
    "image1.jpg",
    "image2.jpg",
    "image3.jpg",
    "image4.jpg"
];

// Animation settings
let currentFrame = 0;
let frameSpeed = 500; // milliseconds

const mainImage = document.getElementById("main-image");

// Display images one after another
function animateImages() {

    mainImage.src = images[currentFrame];

    currentFrame++;

    if (currentFrame >= images.length) {
        currentFrame = 0;
    }

}

// Start animation
setInterval(animateImages, frameSpeed);

2. Reusable playAnimation()

The same idea wrapped in a function. It preloads frames, can play once or loop, and returns a stop function. You can run several animations on one map.

animation.js
// =============================================================
//  animation.js — reusable frame animation for YJD GameTech
//  Usage:  playAnimation("main-image", ["a1.png","a2.png"], 120);
// =============================================================

function playAnimation(elementId, frames, frameSpeed = 500, loop = true) {
    const el = document.getElementById(elementId);
    if (!el || frames.length === 0) return null;

    // Preload so frames don't flicker the first time
    frames.forEach(src => { const img = new Image(); img.src = src; });

    let currentFrame = 0;
    el.src = frames[0];

    const timer = setInterval(() => {
        currentFrame++;
        if (currentFrame >= frames.length) {
            if (!loop) { clearInterval(timer); return; } // play once
            currentFrame = 0;                             // loop
        }
        el.src = frames[currentFrame];
    }, frameSpeed);

    // Return a "stop" button you can call later
    return () => clearInterval(timer);
}

// ---- Examples -----------------------------------------------

// 1. Background that loops forever (rain, traffic, water)
playAnimation("main-image", [
    "street1.jpg", "street2.jpg", "street3.jpg", "street4.jpg"
], 500);

// 2. Play once — e.g. an explosion or a door opening
// playAnimation("door", ["door1.png","door2.png","door3.png"], 120, false);

// 3. Stop an animation later

3. Frames that follow the time of day

Uses getGameTime() from the ready-to-use engine.js. The street in the home-page demo works this way. Load animation.js first.

street.html · script
// Pick different frames depending on the time of day.
// Ask the parent page (game.html) what time it is —
// engine.js shares it through window.getGameTime().
function getGameTime() {
    try { return window.parent.getGameTime(); }
    catch (e) { return "day"; }
}

const framesByTime = {
    day:     ["street-day1.jpg",   "street-day2.jpg"],
    evening: ["street-eve1.jpg",   "street-eve2.jpg"],
    night:   ["street-night1.jpg", "street-night2.jpg"]
};

let stop = playAnimation("main-image", framesByTime[getGameTime()], 400);
let lastTime = getGameTime();

// Every second, check if the time changed and swap the frames
setInterval(() => {
    const now = getGameTime();
    if (now !== lastTime) {
        lastTime = now;
        if (stop) stop();
        stop = playAnimation("main-image", framesByTime[now], 400);
    }
}, 1000);

4. Sprite sheet (CSS only)

Put all frames side by side in one image. CSS slides through them with steps(). It's one download and very smooth, which suits characters.

sprite example
<!-- One image that holds all frames side by side: walk.png (4 frames, 64px each) -->
<div class="hero"></div>

<style>
.hero {
    width: 64px;
    height: 64px;
    background: url("walk.png") 0 0 no-repeat;
    animation: walk 0.6s steps(4) infinite;  /* 4 frames */
    image-rendering: pixelated;
}
@keyframes walk {
    to { background-position: -256px 0; }  /* 4 x 64px */
}
</style>

Tips

Make animations look good

Same size frames

Export every frame at the same width and height, or the picture will jump.

Number your files

Name frames walk1.png, walk2.png… so the order is obvious in the list.

Few frames, good loop

4 to 8 frames is plenty. Make the last frame lead naturally back into the first.

Keep files light

Use compressed JPG/WebP for scenes and PNG for transparent sprites. Small files keep the engine fast on any device.
