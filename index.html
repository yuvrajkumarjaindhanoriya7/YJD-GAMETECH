Manohari Game Engine · by YJD GameTech

Build a living game world from plain HTML files.

Every place in your game is its own HTML page. engine.js links them with W A S D, cycles day, evening and night, and switches the world when your story changes. It runs in any browser, even on low-end hardware.

Start the tutorial Get the code
Click the scene, then press W A S D. Time changes every 20 seconds. Open full screen ↗

What it is

Three ideas run the whole engine

01 · Chunks

Every map is a page

Streets, parks and caves are separate HTML files called chunks. You can design them with images, CSS or a canvas.

02 · Map tables

Keys connect the maps

A small JavaScript object says “from street.html, pressing W goes to park.html.” That's all the level design code you need.

03 · Time + states

The world changes

Separate map tables for day, evening and night, plus story switches like stateone, let the same key lead somewhere new.

How it works

One window, many maps

The player always stays on game.html. Only the iframe inside it changes.

game.htmlHolds one <iframe id="myIframe"> and loads engine.js.
→
engine.jsReads the key you pressed, the current time and the state, then finds the next map.
→
chunk.htmlThe iframe's src becomes the new map, with a quick fade.

Tutorial

Make your first game in 7 steps

You only need a text editor and a browser. The full files are on the Codes page.

Create the project folder

Keep every file in one folder. The engine reads file names, so name maps clearly and use lowercase.

folder structure
my-game/
├── game.html          ← the window your game runs in
├── engine.js          ← moves the player between maps
├── animation.js       ← (optional) frame animation helper
├── street.html        ← a map "chunk"
├── park.html
├── park_sunset.html
├── park_night.html
├── sidewalk.html
└── images/            ← your scene pictures and animation frames

Make the game window

Copy game.html. Set the iframe's src to the first map the player sees, for example street.html. The iframe must keep id="myIframe".

Draw your maps (chunks)

Each map is a full-screen HTML page. The simplest chunk is one picture. Use the chunk.html template if the map should be animated.

park.html
<!-- park.html — one map of your world -->
<!DOCTYPE html>
<html>
<body style="margin:0; overflow:hidden; background:#000">
    <img src="images/park.jpg" alt="Park"
         style="width:100vw; height:100vh; object-fit:cover; display:block">
</body>
</html>

Connect maps with keys

In engine.js, list every map and where each key leads. Remember to add a way back, or the player gets stuck.

engine.js · dayMap
const dayMap = {
    "street.html":   { w: "park.html", a: "sidewalk.html" }, // W = forward, A = left
    "park.html":     { s: "street.html" },                   // S = back
    "sidewalk.html": { d: "street.html" }                    // D = right
};

Add day, evening and night

Copy your day table into eveningMap and nightMap, then point keys to night versions of your maps. Group them in normalWorld. The engine moves to the next time every TIME_STEP.

engine.js · time
const eveningMap = {
    "street.html":      { w: "park_sunset.html" },
    "park_sunset.html": { s: "street.html" }
};

const normalWorld = { day: dayMap, evening: eveningMap, night: nightMap };

const TIME_STEP = MINUTE;   // try 1000 * 20 while testing

Change the story with states

A state is a true/false switch. When it turns on, the engine reads stateoneMaps instead, so the world can change after an event like a car crash.

engine.js · stateone
let stateone = false;   // false = normal city, true = after the crash

// inside handleKey():
if (!stateone && currentFile === "street.html" && keyPressed === "w") {
    stateone = true;    // from now on the engine reads stateoneMaps
}

const stateoneMaps = {
    day: { "park.html": { s: "street_crashed.html" } }
};

Animate and test

Bring maps to life with frame animation (see the Animation page). Open the folder with a local server, for example the VS Code Live Server extension, so the iframe and engine can talk to each other. Then press W A S D.

street.html
<img id="main-image" src="images/street1.jpg" alt="Street">

<script src="animation.js"></script>
<script>
    playAnimation("main-image", [
        "images/street1.jpg", "images/street2.jpg",
        "images/street3.jpg", "images/street4.jpg"
    ], 300); // 300 ms per frame
</script>
  • Press F12 and open the Console to see “Time is now: evening” and crash messages.
  • Shorten TIME_STEP while testing, then set it back.
